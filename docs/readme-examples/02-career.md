# xsmsh7

**影像量測與工程軟體開發｜實驗驗證與 AI 協作**

我有電機工程背景，工作經驗涵蓋影像量測系統與設備控制軟體，包括演算法開發、相機與光源實驗、軟體驗證及產品文件。

我關注如何從實際使用情境定義問題，透過實驗與數據檢查方法，並把經驗整理成可重用的工作流程。目前也持續探索 AI 在軟體開發、數據分析與技術文件中的應用。

## 精選經驗與作品

| 主題 | 工作內容與個人貢獻 |
| :--- | :--- |
| 影像量測系統開發 | 參與影像量刀儀的軟體與演算法開發、相機與光源實驗、量測驗證及產品文件撰寫。 |
| 設備控制軟體開發 | 參與超音波驅動軟體前期開發，處理設備通訊、參數設定、操作流程與測試。 |
| AI Engineering | 將工作中的 AI 使用經驗整理為協作方法，探索軟體開發、數據分析與技術文件的可重用流程。 |

## 技術與目前方向

影像量測、演算法開發、實驗設計與驗證、設備通訊、Git / GitHub、技術文件。

持續整理 SOP、實驗格式與產品文件，並探索 AI 如何支援開發、分析與知識交接。
