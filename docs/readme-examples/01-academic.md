# xsmsh7

**影像處理 · AI 工程 · 系統開發**

我有電機工程背景，做過影像復原研究與數位邏輯實作。目前關注如何把 AI 融入工程工作，將經驗、文件與工作方法整理成可以重複使用的流程。

我喜歡理解問題背後的原因，透過實驗比較方法，也記錄設計選擇與限制。
